# SIGILOS

Um protótipo curto de jogo narrativo em texto, jogado pelo terminal. Experimente
as opções, preste atenção ao que acontece e descubra no seu ritmo.

## Como experimentar

É necessário ter Python 3.8 ou superior. Não é preciso instalar bibliotecas.

No Windows, abra um terminal nesta pasta e execute:

```powershell
py main.py
```

Se `py` não estiver disponível, tente `python main.py`.

Escolha uma opção pelo número exibido ou escrevendo o nome. Digite `d` para
consultar o diário e `s` para sair. Depois de uma tentativa, pressione Enter
para começar outra ou `s` para encerrar.

## Para preservar a descoberta

Evite abrir a pasta `content/` antes de jogar: ela contém material que pode
antecipar a experiência. O jogo guarda localmente o diário e um registro das
tentativas na pasta `saves/`; esses arquivos não são necessários para iniciar.

## Feedback

Ao experimentar, conte o que chamou sua atenção, o que ficou confuso e se alguma
parte pareceu injusta. Se quiser compartilhar os registros de `saves/`, confira
antes se está confortável em revelar suas tentativas.
